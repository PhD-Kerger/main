# API Endpoints

This document provides a summary of the available services and their respective ports in this workspace.

| Service            | Port | Description                                           |
| :----------------- | :--- | :---------------------------------------------------- |
| **OSRM**           | 5001 | Open Source Routing Machine for road network routing. |
| **Open Topo Data** | 5002 | REST API server for elevation data queries.           |
| **KeplerGL**       | 5003 | Geospatial data visualization web interface.          |
| **Grafana**        | 5004 | Visualization and dashboarding platform.              |
| **Open-Meteo**     | 5005 | Historical weather data and forecast API.             |
| **TimescaleDB**    | 5432 | PostgreSQL-based time-series database.                |
